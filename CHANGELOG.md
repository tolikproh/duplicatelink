# Changelog

## [Unreleased]

### Добавлено
- **Параллельное хеширование с воркерами**: Теперь сканирование выполняется с помощью пула воркеров (от 3 до 10), что ускоряет обработку файлов без перегрузки диска
- **Флаг `-workers`**: Возможность настройки количества воркеров через командную строку (по умолчанию 3)
- **Двухэтапное сканирование с прогресс-барами**:
  - Этап 1: Сбор списка файлов (с прогресс-баром)
  - Этап 2: Параллельное хеширование файлов воркерами (с прогресс-баром)
- **Потокобезопасная структура `SafeHashMap`**: Обеспечивает безопасную запись хешей из нескольких горутин
- **Улучшенная архитектура**: Использование каналов Go и sync.WaitGroup для эффективной параллельной обработки

### Изменено
- **Функция `FindDuplicates()`**: Переписана для поддержки параллельной обработки с воркерами
- **Процесс сканирования**: Разделен на два четких этапа с отдельной визуализацией прогресса
- **Вывод информации**: Добавлено отображение количества воркеров и этапов сканирования

### Технические детали
- Используется пул горутин для параллельного хеширования файлов
- Map инициализируется с начальной емкостью равной количеству файлов для оптимизации памяти
- Mutex защищает запись в map от race conditions
- Каналы используются для передачи задач воркерам

### Производительность
- Значительное ускорение на больших наборах файлов
- Эффективное использование многоядерных процессоров
- Настраиваемое количество воркеров для оптимизации под конкретное оборудование

## Пример использования

```bash
# С параметрами по умолчанию (3 воркера)
./duplicatelink /path/to/folder

# С настраиваемым количеством воркеров
./duplicatelink -workers 5 /path/to/folder

# С максимальным количеством воркеров
./duplicatelink -workers 10 -hash sha1 /path/to/folder
```
