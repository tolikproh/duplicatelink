# Архитектура проекта DuplicateLink

## Обзор

DuplicateLink - это утилита командной строки для поиска и управления дубликатами файлов. Проект следует стандартной структуре Go проектов с разделением на модули.

## Структура проекта

```
duplicatelink/
├── cmd/
│   └── duplicatelink/       # Точка входа приложения
│       └── main.go          # Парсинг аргументов и координация модулей
├── internal/                # Внутренние пакеты
│   ├── models/             # Модели данных
│   │   └── models.go       # Структуры для хранения данных
│   ├── scanner/            # Модуль сканирования
│   │   └── scanner.go      # Поиск дубликатов, хеширование
│   ├── cleaner/            # Модуль очистки
│   │   └── cleaner.go      # Удаление дубликатов, создание симлинков
│   └── restore/            # Модуль восстановления
│       └── restore.go      # Восстановление из бэкапа
├── bin/                    # Скомпилированные бинарные файлы
├── docs/                   # Документация
│   ├── ARCHITECTURE.md     # Этот файл
│   ├── DISCLAIMER.md       # Отказ от ответственности
│   └── LICENSE             # Лицензия
├── Makefile               # Автоматизация сборки
├── go.mod                 # Зависимости Go
├── go.sum                 # Контрольные суммы зависимостей
├── .gitignore            # Игнорируемые файлы
└── README.md             # Основная документация
```

## Модули

### cmd/duplicatelink

**Назначение:** Точка входа приложения

**Ответственность:**
- Парсинг аргументов командной строки
- Валидация входных параметров
- Координация работы модулей
- Обработка ошибок верхнего уровня

### internal/models

**Назначение:** Определение структур данных

**Основные типы:**
- `FileHash` - информация о файле и его хеше
- `DuplicateGroup` - группа дубликатов с одинаковым хешем
- `ScanResult` - результат сканирования директории
- `RestoreAction` - действие для восстановления
- `ErrorInfo` - информация об ошибке
- `RestoreData` - данные для восстановления

### internal/scanner

**Назначение:** Поиск и анализ дубликатов

**Основные функции:**
- `FindDuplicates()` - рекурсивное сканирование директории с параллельным хешированием
- `calculateHash()` - вычисление SHA1/MD5 хешей
- `PrintDuplicates()` - вывод результатов в консоль
- `SaveResultsToJSON()` - сохранение результатов в JSON
- `SaveScanReportMarkdown()` - генерация Markdown отчета
- `LoadResultsFromJSON()` - загрузка результатов из JSON

**Алгоритмы хеширования:**
- SHA1 (по умолчанию)
- MD5

**Архитектура параллельной обработки:**

Сканирование выполняется в два этапа:

1. **Этап 1: Сбор списка файлов**
   - Рекурсивный обход файловой системы
   - Применение правил .dupignore
   - Фильтрация скрытых файлов (если не включена опция)
   - Подсчет общего количества файлов
   - Визуализация прогресса через progress-bar

2. **Этап 2: Параллельное хеширование**
   - Создание пула воркеров (по умолчанию 3, настраивается через `-workers`)
   - Распределение файлов между воркерами через каналы
   - Потокобезопасное сохранение хешей в `SafeHashMap`
   - Визуализация прогресса через progress-bar

**Потокобезопасность:**
- `SafeHashMap` - структура с mutex для безопасной записи из нескольких горутин
- `sync.WaitGroup` - синхронизация завершения всех воркеров
- Каналы Go для передачи задач воркерам

### internal/cleaner

**Назначение:** Удаление дубликатов и создание симлинков

**Основные функции:**
- `CleanDuplicates()` - основная логика очистки
- `AskConfirmation()` - запрос подтверждения
- `getFileCategory()` - определение категории файла
- `copyFile()` - копирование файла с сохранением прав

**Процесс очистки:**
1. Создание структуры папок по категориям
2. Копирование одного экземпляра каждого дубликата
3. Удаление остальных дубликатов
4. Создание символических ссылок
5. Генерация отчетов (Markdown и JSON)
6. Логирование ошибок

**Категории файлов:**
- image (jpg, png, gif, ...)
- video (mp4, avi, mkv, ...)
- audio (mp3, wav, flac, ...)
- document (pdf, doc, txt, ...)
- archive (zip, rar, 7z, ...)
- code (go, py, js, ...)
- data (json, xml, yaml, ...)
- other (остальные)

### internal/restore

**Назначение:** Восстановление исходного состояния

**Основные функции:**
- `RestoreFromBackup()` - восстановление из JSON
- `copyFile()` - копирование файла

**Процесс восстановления:**
1. Чтение JSON файла восстановления
2. Удаление символических ссылок
3. Копирование оригинальных файлов обратно
4. Подтверждение операций пользователем

## Поток данных

### Режим сканирования (SCAN)

```
1. Пользователь -> Аргументы CLI (путь, hash, workers)
2. main.go -> scanner.FindDuplicates()
3. scanner -> Этап 1: Сбор списка файлов
   - Обход файловой системы
   - Применение .dupignore правил
   - Progress-bar "Сбор списка файлов"
4. scanner -> Этап 2: Параллельное хеширование
   - Создание пула воркеров
   - Распределение файлов по воркерам
   - Вычисление хешей (SHA1/MD5) параллельно
   - Потокобезопасное сохранение в SafeHashMap
   - Progress-bar "Хеширование"
5. scanner -> Группировка по хешам
6. scanner -> Сохранение в JSON и Markdown
7. scanner -> Пользователь (результаты)
```

### Режим очистки (CLEAN)

```
1. Пользователь -> JSON файл сканирования
2. main.go -> scanner.LoadResultsFromJSON()
3. main.go -> cleaner.AskConfirmation()
4. main.go -> cleaner.CleanDuplicates()
5. cleaner -> Создание структуры папок
6. cleaner -> Копирование мастер-файлов
7. cleaner -> Удаление дубликатов
8. cleaner -> Создание симлинков
9. cleaner -> Генерация отчетов (MD + JSON)
10. cleaner -> Пользователь (отчеты)
```

### Режим восстановления (RESTORE)

```
1. Пользователь -> JSON файл восстановления
2. main.go -> restore.RestoreFromBackup()
3. restore -> Чтение JSON
4. restore -> Подтверждение
5. restore -> Удаление симлинков
6. restore -> Копирование файлов обратно
7. restore -> Пользователь (статус)
```

## Обработка ошибок

### Стратегия обработки ошибок

1. **Уровень операций с файлами:**
   - Логирование в консоль с префиксом ⚠️
   - Сохранение в `ErrorInfo` структуру
   - Продолжение обработки остальных файлов

2. **Уровень модулей:**
   - Возврат ошибок через `error` интерфейс
   - Форматирование с использованием `fmt.Errorf()`

3. **Уровень приложения:**
   - Вывод ошибок в stderr
   - Завершение с кодом 1 при критических ошибках
   - Завершение с кодом 0 при успешном выполнении

### Типы ошибок

- `copy_failed` - ошибка копирования файла
- `remove_failed` - ошибка удаления файла
- `symlink_failed` - ошибка создания симлинка

## Безопасность

### Меры предосторожности

1. **Подтверждение операций:**
   - Запрос подтверждения перед очисткой
   - Запрос подтверждения перед восстановлением

2. **Сохранение данных:**
   - Копирование файлов перед удалением
   - Создание файлов восстановления
   - Отдельный JSON только с ошибками

3. **Валидация:**
   - Проверка существования директорий
   - Валидация алгоритмов хеширования
   - Проверка режимов работы

4. **Права доступа:**
   - Сохранение прав доступа при копировании
   - Создание директорий с правами 0755
   - Создание файлов с правами 0644

## Расширяемость

### Добавление нового алгоритма хеширования

1. Добавить case в `scanner.calculateHash()`
2. Обновить валидацию в `main.go`
3. Обновить документацию

### Добавление новой категории файлов

1. Добавить категорию в `cleaner.getFileCategory()`
2. Обновить документацию

### Добавление нового режима работы

1. Создать новый модуль в `internal/`
2. Добавить обработку в `main.go`
3. Обновить справку и документацию
