# Руководство по .dupignore

Этот файл позволяет исключать пути при сканировании (SCAN) и при очистке (CLEAN). Формат вдохновлён `.gitignore` и поддерживает базовые паттерны и исключения.

## Основы

- Размещение: `.dupignore` в корне папки, которую вы сканируете
- Комментарии: строки, начинающиеся с `#`
- Пустые строки: игнорируются
- Порядок важен: применяется правило последнего совпадения

## Типы правил

- Игнорировать папку: `dir/` — игнорирует `dir` и весь её содержимый
- Игнорировать файлы по шаблону: `*.bak`, `temp/*`
- Исключение (разрешение) с `!`: `!*.jpg` — отменяет игнорирование для совпадающих файлов

Примечания:
- Шаблоны без завершающего `/` применяются только к файлам, не к папкам
- Шаблоны с `/` на конце применяются к папкам и их содержимому

## Семантика (как работает сопоставление)

- Проверка производится по пути, относительному от корня, с `/` в качестве разделителя
- Последнее совпавшее правило определяет судьбу пути:
  - Обычное правило → путь игнорируется
  - Правило с `!` → путь разрешается (не игнорируется)
- Папки игнорируются только правилами, заканчивающимися `/`

## Примеры

### 1. Игнорировать временные и резервные файлы
```
temp/
cache/
*.bak
*.tmp
```

### 2. Игнорировать всё, кроме фотографий и видео
```
# Игнорировать все файлы
*

# Разрешить фото
!*.jpg
!*.jpeg
!*.png
!*.gif
!*.bmp
!*.webp
!*.tiff
!*.tif
!*.heic
!*.heif

# Разрешить RAW-форматы
!*.cr2
!*.cr3
!*.nef
!*.arw
!*.dng

# Разрешить видео
!*.mp4
!*.mov
!*.mkv
!*.avi
!*.webm
```

См. расширенный шаблон: docs/dupignore-photos-videos.example

### 3. Игнорировать всё, кроме фотографий в подпапке `Photos/`
```
*
!Photos/*.jpg
!Photos/*.jpeg
!Photos/*.png
Photos/tmp/     # При необходимости исключить подпапку
```

### 4. Игнорировать документы, но разрешить отчёты Markdown
```
*.pdf
*.doc
*.docx
*.xls
*.xlsx
*.ppt
*.pptx

# Разрешить Markdown
!*.md
```

### 5. Игнорировать папки проекта, оставляя только данные
```
node_modules/
.vscode/
build/
.dist/
.tmp/

# Разрешить данные
!data/**
```

Примечание: шаблон `**` в текущей реализации обрабатывается как обычная звезда в сегменте пути (подстановки), но поведение рекурсивного матчинга может быть ограничено. Для точной адресации используйте явные подпапки: `data/`, `data/images/` и т.д.

## Проверка работы

1. Создайте `.dupignore` в корне:
```
echo -e "*\n!*.jpg" > .dupignore
```
2. Запустите сканирование:
```
duplicatelink -hash sha1 /path/to/folder
```
3. Убедитесь, что в отчётах включены только разрешённые типы

## Ограничения

- Не поддерживаются условия по размеру/времени/метаданным — только по путям/расширениям
- Семантика приближена к `.gitignore`, но не полностью идентична (например, обработка `**` ограничена)
- Файл `.dupignore` применятся в режиме CLEAN только к файлам (директории фильтруются при сканировании)

## Рекомендации

- Ставьте общие правила выше, а точные разрешающие ниже (последнее совпадение важно)
- Держите `.dupignore` под контролем версий, если шаблон общий для команды
- Создавайте разные шаблоны для разных задач и переключайте их при необходимости
